# 幻獣デュエル ～ネオ・アリーナ～

スマホで遊べる オリジナルカードデュエルゲーム（1ファイルの HTML ゲーム）。

▶ あそぶ: https://ryowatanabe1161-svg.github.io/genjuu-duel/

- 140種のオリジナルカード（モンスター・じゅもん・しかけ、精霊獣のカード）、プリセットデッキ6種、カード図鑑。同じカードはデッキに3枚まで、ライフは6000でスタート
- CPUと対戦 ／ 2人で対戦（1台を交代）
- オンライン対戦（2台・WebRTC P2P / PeerJS）: 「部屋を作る」で出たコードを相手に送ってね
- カード名・イラスト・テキストはすべてオリジナルです
